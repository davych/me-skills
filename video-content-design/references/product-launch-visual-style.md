# 产品发布片式视觉风格

## 可直接引用的风格描述

高反差黑白底与大留白，配上紧凑的大字和清楚的音乐重拍。字标、数字、卡片群或单个物件轮流成为画面中心。信息页清爽，卡片随节奏逐步出现。章节转折可以换成冷色水彩球体、短暂的高饱和色场或近黑背景下的铜色地平线。顶部小字和底部细刻度提供位置线索。动作短促，落位后充分停留，首尾用同一个问题、界面或物件形成呼应。

这套视觉语言适用于不同片长。先按内容选择画面类型，再决定每段的展示时间、动作数量和音乐起落。下面的画面类型可增减、重用或调换，按实际故事组织。

## 构图与留白

| 画面 | 视觉特征 |
| --- | --- |
| 问题与首尾呼应 | 近白底、大留白，一个输入框、问句或物件先出现。输入、发送或物件状态的变化引出主题，结尾带着结果回到同一元素。旁白片也可用一句提问或原有场景承接。 |
| 品牌、数字和关键动作词 | 近黑底上的超大白字，或近白底上的墨黑字。一个词、数字或字标占主要面积，短说明与少量标记放在次要位置。数字变化以真实内容为依据。 |
| 能力、角色和交接物 | 不对称卡片群逐步建立层级，一张大卡片承载核心信息，周围小卡片补充状态和产物。可用短色带关联角色或能力，正文停留时间随信息量安排。 |
| 主物件与能力展开 | 居中球体、界面或物件占主画面，两侧短条目依次出现。冷色漫射和水彩纹理可营造轻盈感。详细流程也可用左标题、右侧大图的构图，主图宽度从约六成起试。 |
| 章节高潮 | 短暂铺满画面的饱和色场与超大标题，在音乐的一个重要落点上展开。连续暗场可用低位铜色弧光保持深度，把可读的文字留在安静的暗部。 |
| 失败、验证和结果 | 用节点、回路或事件路径展示失败、修复、复测和决策的联系。量化曲线使用真实数据，流程信息使用路径和状态标签。结果可以占据画面中央，也可以用大结论与记录图形成两栏。 |

主体周围的空白留给阅读和运动。信息多的画面靠对齐、分组和明暗层次保持秩序。顶部可以有字标、章节和时间，底部是一条细刻度线与一个当前进度点。两者贴近边缘，和主画面之间留出空隙。品牌片头和片尾可以收起这些边缘信息。

## 字体和信息层级

- **主标题**是字面清楚的粗体无衬线，字距略紧，通常一到两行。品牌、数字和动作词可以直接承担主图。详细流程镜头里，标题收在次要位置，把主要面积留给图示。并排字标保持同基线与相近的视觉重量。
- **短语与单位**可用少量斜体衬线，与数字或无衬线大字形成节奏上的区别，例如数字后的单位、结论中的短语。中文以清楚可读的字体和字重层级为先。
- **说明与图内文字**沿用同一无衬线体系。说明较小、字重适中，重要的节点名和数字更有分量。节点的短说明与标题之间有清楚的间隔。
- **章节、刻度和元信息**用较小、带字距的等宽字。它们负责定位，处于较低的视觉层级。真正要读清的状态名称以正文或图内标题呈现。

以 1920×1080 的横版画面为例，Inter 和 JetBrains Mono 可以分别承担叙述和标记，少量英文斜体短语可选 Instrument Serif。主画面的字标或动作词可从 160–300 px 起试，章节标题约 80–100 px，正文约 26–36 px，章节和刻度约 14–18 px。外侧留约 80–100 px 安全空间。实际尺寸随画幅、语言、最长文本和观看尺寸调整。

## 色彩、光线和表面

整体以近白、近黑和墨色为底。浅色章节用纸面般的清晰度承载信息，深色章节用安静的暗部托起大字。色彩集中在少数有意义的物件或转折，高潮段落可以短暂充满画面。段内保持材质连续，明暗切换对应内容转折。以下是一组可调整的示例色。

| 色彩角色 | 示例 | 画面里的作用 |
| --- | --- | --- |
| 纸面与墨色 | #FAFAFA、#141414 | 浅色信息页与高反差大字。需要暖感时可向纸白偏移。 |
| 冷色漫射与水彩 | #D9E9FA、#5265DE、#FFA2BE | 蓝白球体或主物件中的流动色块，少量粉色带来层次。 |
| 短暂高饱和色场 | #4035C9、#F04E4F、#FFB162 | 紫、红、橙在关键转折中扩展为大面积色场。 |
| 暗场与低位弧光 | #070708、#10101F、#ECB48C | 近黑与深蓝托住文字，铜色弧光从画面底部升起，连续镜头共享光源与弧线位置。 |
| 状态强调 | 沿用项目的状态色 | 失败、修复、验证等状态同时用文字或图形说明。 |

浅底卡片用接近纸白的灰、柔圆角与极轻阴影，核心卡片可以反转成黑底白字。深底条目用暗灰，当前条目可短暂反转成白底。水彩、渐变、稀疏星点和发光放在背景或主物件层，文字区域保持清晰。球体转动、色场流动和弧光呼吸用缓慢变化延续段内运动。

## 线条与动效气质

- **线条有层级。** 背景路径细而安静，当前路径更亮、更实。转弯用长而圆滑的弧线，分流和汇合有清楚的起讫点。圆点的亮芯与淡光晕让当前位置一眼可辨。
- **重拍有落点。** 明暗硬切、主标题落位、卡片亮相或发送动作与声音中的实际重音同步。揭字、计数、短位移与轻点击可落在分拍。短模糊和轻缩放用于少量关键动作，动效的清晰落位与声音瞬态一起校正。
- **动作短促，停留清楚。** 线条沿路径推进，小光点贴着线走，标签在节点处落位。文字和卡片出现后给足阅读时间。详细讲解靠局部变化引导视线，章节转折才改变大构图。音乐持续时，主体也可以保持稳定。
- **首尾共用视觉元素。** 输入框、问句、字标或主物件占据相近位置。开场提出问题或展开主题，收尾让实际结果回到这个元素。发送、归拢、结果定格或简短致谢都可以完成收束，按题材与声音安排选择。
