# 产品发布片式视觉风格

## 可直接引用的风格描述

产品发布片的舞台感，配上编辑式排版的清晰度。近黑场景里有稀疏星点和低位柔光，暖白信息场景里有墨黑文字、细灰线和留白。画面通常由一个主体主导。它可以是一条不断变化的流程、一个关键数字，或一个正在切换状态的界面。标题短而紧凑，边缘保留细小的章节名、时间和刻度。色彩集中在当前节点和关键状态上，运动干净、明快，转折处有短暂停顿。

## 构图与留白

| 画面 | 视觉特征 |
| --- | --- |
| 品牌片头和片尾 | 全幅深色，字标在同一水平线上，中心符号是两边构图的轴。细曲线在轴的两侧对称展开，四周留出宽阔暗部。 |
| 流程、界面和交接物 | 暖白底上，左侧是短标题与一两行说明，右侧主图占画面宽度约六成。图里的节点、卡片和连线构成主要视觉重量。 |
| 数据和里程碑 | 一项指标或一个当前事件先入眼。细刻度、图例和历史节点形成安静的背景层。折线末端、放大的数字或单个高亮事件呈现这一拍的新信息。 |
| 失败、转折和验证 | 深色画面把注意力集中到一条路线及其回路。失败点留在原位，修复与复测用连续线接回记录。关键流程图向画面中轴放大，左侧文案退成小注。 |

主体周围的空白留给阅读和运动。信息多的画面靠对齐、分组和明暗层次保持秩序。顶部可以有字标、章节和时间，底部是一条细刻度线与一个当前进度点。两者贴近边缘，和主画面之间留出空隙。品牌片头和片尾可以收起这些边缘信息。

## 字体和信息层级

- **主标题**是字面清楚的粗体无衬线，字距略紧，通常一到两行。流程镜头里的标题收在左侧，主图占据更大的面积。品牌画面里，两侧字标保持同基线与相近的视觉重量。
- **说明与图内文字**沿用同一无衬线体系。说明较小、字重适中，重要的节点名和数字更有分量。节点的短说明与标题之间有清楚的间隔。
- **章节、刻度和元信息**用较小、带字距的等宽字。它们负责定位，处于较低的视觉层级。真正要读清的状态名称以正文或图内标题呈现。

## 色彩、光线和表面

整体以近黑、暖白和墨黑为底，大面积颜色保持低饱和度。暖白章节接近纸面，深色章节接近舞台。明暗变化有章节含义，常见于从讲解切到转折，或从过程回到品牌画面。以下是一组示例色。

| 色彩角色 | 示例 | 画面里的作用 |
| --- | --- | --- |
| 纸面与墨色 | #F5F3EE、#14121A | 浅色信息页的底色与主要文字。 |
| 深色舞台 | #0D0B14、#1B142C、#3B255B | 近黑为主，暗紫柔光从右下向近黑淡出。稀疏星点提供景深。 |
| 流程强调 | #6045DE、#B8A8FF | 浅底用紫色标当前路径，暗底用淡紫强调轨迹、节点与字标交点。 |
| 状态强调 | #FF876F、#86EFD0 | 珊瑚色标出失败，薄荷绿标出验证或证据收束。颜色和文字一起表达状态。 |

浅底卡片接近纸白，配薄边、柔圆角与极轻阴影。深底卡片可以有轻微半透明感，保留清楚的文字对比。浅色点阵主要留在主图一侧，星点和渐变则铺在深色画面的后层。发光集中在少数活动节点、轨迹或交点。

## 线条与动效气质

- **线条有层级。** 背景路径细而安静，当前路径更亮、更实。转弯用长而圆滑的弧线，分流和汇合有清楚的起讫点。圆点的亮芯与淡光晕让当前位置一眼可辨。
- **动作短促，停留清楚。** 线条沿路径推进，小光点贴着线走，标签在节点处稳稳落位。文字和卡片以短淡入或小位移出现，停住后保持可读。明暗章节间可用清楚的切换，进入关键结果时可以有一次缓慢的放大或移向中心。
- **首尾对称有实际内容。**  具有创意,首位呼应。
