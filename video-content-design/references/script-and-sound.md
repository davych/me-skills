# 台词与声音设计

## 声音风格

声音清爽、有推动力，也有轻重和呼吸。音乐驱动的片子用清楚的鼓点、温和的贝斯、通透的和弦与稀疏的拨弦合成音组织段落，轻点击和短上升音连接可见的动作。有旁白时，讲述像一个熟悉内容的人带观众看画面，配乐给语句留出空间。关键点前可以抽掉一层，结果出现时再恢复主拍，结尾让和声与尾音自然收住。

## 按内容安排音乐长度

先依据叙事、阅读和实际语音确定各段需要的时间，再选音乐速度与乐句结构。采用上述声音风格时，BPM、拍号、总拍数和段落数量都按新内容选择。已有歌曲或用户指定音乐时，以其实际结构和重音为依据。

可从以下能量变化组织编曲，并按需要扩展讲解段或增加转折。

| 叙事阶段 | 配乐与声音处理 |
| --- | --- |
| 提问、引入 | 稀疏拨弦、柔和和弦或留白，打字、物件出现等动作配轻提示音。 |
| 主题或品牌亮相 | 低鼓和贝斯进入，让字标或首个关键结果落在清楚的重拍。 |
| 内容展开 | 保持可辨认的律动，随信息密度增减打击乐、旋律和低频，章节间改变配器或和声。 |
| 转折与验证 | 用短暂断拍、减层、上升音或单个低频冲击提示变化，再接回主拍。 |
| 结论与收尾 | 和声解决，减少节奏层，留出自然衰减。音乐结束点与最终画面稳定后的停留一起安排。 |

需要延长时，围绕仍在展开的内容续写乐句或增添小节，在配器、和声或轻重上形成变化，并为新章节写连接。旁白句尾和复杂图示所需的停留决定具体剪接位置。音乐长度调整后重新安排结尾的和声解决与残响，确保完整收声。

## 画面与声音的共同落点

- 用一份提示时间表维护章节起止、主要动作、声音重音和语音空档。按项目采用秒或拍作为主要单位，画面与配乐从这份表生成各自的时序。标题、文字和卡片需要停留到观众读完。
- 章节切换、品牌亮相和结论适合落在小节重拍，揭字、计数、点击和卡片展开可用半拍或更细的分拍。长讲解优先遵循语句起止、重音和自然停顿，再选合适的音乐落点。段内通过音色和强弱维持律动，画面按内容需要改变。
- 恒速音乐先量出实际首拍时间 `t0`。第 `b` 拍的时间为 `t0 + b × 60 / BPM`，其中首拍记作 `b = 0`，分拍可用小数。Remotion 帧号为 `round(time × fps)`，音频样点为 `round(time × sampleRate)`。各边界独立从绝对时间换算，片段长度取结束帧减开始帧，避免逐拍取整导致漂移。
- 变速音乐或自由节奏按实测拍点记录时间。需要引导一个重音时，可让画面提前开始运动，在声音瞬态处完成清晰落位。试听时核对导出的声音和画面，包含音频前导静音、压缩格式延迟及动画的缓动时间。

## 台词与首尾

- **问候。** 有旁白的介绍片可以从一句简短的 greeting 开始。语气像对面有人，必要时接一句观众接下来会看到什么。「大家好，今天我们一起看看……」或「Hi, everyone. Let’s take a look.」都可按内容改写。品牌名在需要辨认时说一次。
- **换页。** 把问候和第一页台词写成两段。问候收完，画面和音乐留一个呼吸，再落到第一页的第一句。约 1–2 秒可用作试剪起点，最后按实际收声、换页和第一句起音判断。短片、冷开场和无旁白作品的起点由题材决定。
- **讲解。** 台词说观众需要理解的关系、原因和变化，屏幕给出名称、数字和证据。短句为主，长句有清楚的重音和换气点。只说一遍的关键术语可以在画面上留得更久。
- **致谢。** 先让最后一个结果落地，再留一个呼吸说「谢谢观看」或「Thanks so much for watching.」。致谢可以落在片尾字标稳定、轨迹归拢或结果定格的时候。最后一个音节结束后，留一点画面和音乐尾音。

## 配音

音色和语言跟着受众与题材选，问候、讲解和致谢听起来像同一个人。问候轻松，正文重音清楚，致谢自然收声。已有配音按实际音轨对齐。需要录制或合成时，用一段带真实画面和背景音的样片检查音色、快慢、重音与停顿。品牌、缩写、人名、日期和数字按听众熟悉的读法标注，屏幕可沿用原拼写。发现一句挤得太满时，先给语句和画面增加停留。用户允许改写台词时，也可以试更短的表达。

## 背景音乐和音效

- **配器和律动。** 可用短尾的低鼓、温和贝斯、通透和弦与少量拨弦音建立清楚的主拍。八分音符的高频打击乐推动运动，更密的填充留给少数过门。正讲话或需要读复杂信息时降低音乐密度，结句和结果出现后再恢复层次。声音的轻重对应这一段要强调的内容。
- **环境声与提示音。** 环境声交代空间，提示音标记有含义的动作，例如节点确认、流程汇合或结果出现。视觉焦点已经足够清楚的地方可以留白。台词段的音乐宜保持清楚的语音空间，按实际混音调整音乐和音效的音量。
- **混音。** 原创或选用的配乐先与关键画面合看，再调整音乐、动作音和旁白的相对音量。有旁白时围绕语音安排减层和音量变化，语句结束后平滑恢复。综合响度和真峰值按交付平台与听感确定，预留编码余量。
- **听最终合成。** 用 1× 检查首个重拍、章节加减层、最满的一段以及结尾止音。有旁白时再听问候到第一句、结论到致谢，确认每个词清楚。检查混音无削波、尾音完整，变速后的音轨以实际起止点对齐，保留必要的音高与自然停顿。
